  1. git clone https://github.com/dezzorigin/umkm-analytics.git

    Butuh: gcc + make. Tanpa dependensi lain.

  2. make

    Menghasilkan binary ./algoritmaSorting. Pesan clean tersedia: make clean.

  3. ./algoritmaSorting

    Menu interaktif: 1 Sorting Dasar (Bubble / Insertion / Selection, 1000 integer), 2 Advance Sorting (Merge / Quick / Shell, 3000 kata dari words.txt), 3 keluar. Tiap pilihan menampilkan data sebelum shuffle, sesudah shuffle, sesudah sorting, lalu waktu eksekusi.

  4. make test

    Smoke test: menjalankan binary dan meng-assert outputnya — hasil Bubble terurut menaik, hasil Merge terurut leksikografis, input tidak valid ditolak. Dipakai juga oleh CI.
